# Ubuntu Server, Docker and Database Mentoring

This repository documents an academic technical mentoring process focused on Ubuntu Server, Docker, Docker Compose, and containerized database services.

## Topics covered

- Ubuntu Server installation and initial configuration.
- Virtualized environments using VMware and VirtualBox.
- Docker installation, services, permissions, and user groups.
- Docker Compose structure and configuration.
- Ports, volumes, environment variables, and data persistence.
- MariaDB, PostgreSQL, and MySQL containers.
- Container status, logs, connectivity, and troubleshooting.

## Mentoring approach

The sessions combined:

- Conceptual explanations.
- Guided installation and configuration.
- Command-line demonstrations.
- Troubleshooting of environment and connectivity issues.
- Review of Docker Compose files.
- Validation of database containers.
- Support for structured technical documentation.

## Results

The institutional record shows academic results progressing from `7.0/10` and `7.6/10` to `10/10`, equivalent to relative increases of **42.9%** and **31.6%**, respectively.

The mentoring process also supported the preparation of a 30-page technical manual containing procedures, screenshots, configuration examples, validation steps, and troubleshooting guidance.
